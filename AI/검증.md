Probability-based metric : 확률 기반 평가 방법 
- 모델 답변이 문법적으로 정확하며 자연스럽고 논리적 흐름을 따르는지 측정 가능 
- 모델 간 미세한 성능 차이를 구별해야 하거나 연속적인 점수가 필요한 평가 시스템에 적합한 방법 


Form-filling paradigm  
- 평가 결과를 주어진 형태(form)에 따라 출력하도록 함(filling)으로써 결과의 일관성 및 설명 가능성 높임 
- G-Eval
  - Task Introduction  : 평가자(LLM) 에게 역할 부여 
  - Evaluation Criteria : 평가 기준 정의 
  - Evaluation Steps : LLM 이 스스로 평가 절차를 생성 
  - Input Context + Input Target : 실제 평가 대상 투입 
  - G-Eval 결과 : LLM 이 각 점수에 확률을 부여 -> 가중 합산으로 최종 점수 산출 
  - 상세 : 사람이 평가 과제에 대한 전반적 설명, 평가기준에 대한 설명을 프롬프트로 입력 -> LLM 은 해당 프롬프트를 바탕으로 CoT(Chain-of-Thought) 기법으로 단계적인 평가 방법(Evaluation Steps)을 자동으로 형성
    -> 평가자 LLM 에 평가 대상문서와 출력 형태에 대한 요구 프롬프트에 추가한다. -> 토큰 단위의 출력 확률에 가중치를 부여한 점수 체계 기반으로 평가 대상 LLM 의 품질 평가


LLM-as-a-judge

- LLM 이 평가자로서 평가대상 모델이 생성한 출력물 평가 
- 설명가능성과 투명성 향상 
- 평가자 LLM 이 단순 점수가 아닌 이유에 대한 설명과 상세 근거를 함께 제공하고 어떠한 과정을 거쳐 판단 진행했는지 설명함 
- RLHF(Reinforcement Learning Human Feedback) : 사람의 피드백으로 LLM 을 강화학습하는 기법 
- Chatrbot Arena 크라우드 소싱(crowd sourcing ) 플랫폼 이용 
- MT-Bench 와 같이 multi-turn question set 활용
